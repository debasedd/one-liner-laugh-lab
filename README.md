# One-Liner Laugh Lab

[![One-Liner Laugh Lab](https://make.fun/badge/u-suroso-69-one-liner-laugh-lab-6ccf3aae.svg)](https://make.fun/c/u-suroso-69-one-liner-laugh-lab-6ccf3aae)

A tiny program for the [One-Liner Laugh Lab](https://make.fun/c/u-suroso-69-one-liner-laugh-lab-6ccf3aae) bounty on [make.fun](https://make.fun).

It writes one line to `/output/entry.txt` — a short funny line answering
the prompt, the excuse a robot vacuum gives after eating a sock:

> The sock came at me first — I just finished the job, and it now enjoys a quiet retirement inside my dustbin.

Run it with:

```sh
python3 main.py
```
